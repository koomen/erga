Let another agent edit this page

Paste this into an agent that can run commands on this computer (Claude Code, Codex…), then explain what you want it to do.

Anyone with this token can edit the document as your agent. New token turns the old one off; restarting the editor does too.

This page can't be paused

Pausing stops a page from reacting to clicks and keys (slides that advance on click, a game), so you can edit the text inside it. This page doesn't support pausing yet.

Select text for the style bar, or type Markdown: **bold**, *italic*, `code`. Click into any text on the page and type. Edits are written to the file on disk as you go. ⌘-click a link to open it.

Others editing the page show as carets with their names, and their edits are marked in their colour. ⌘Z only undoes your own edits; the agent panel has its own undo for your agent's.
