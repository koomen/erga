Erga is a collaborative environment for expressing ideas with AI. It's meant to fill the gap between Google Docs, where the user writes everything by hand in a narrowly constrained format, and Claude Artifacts, where the user has great expressive freedom but can only exercise it by asking an agent to do everything for them.

It gives users unlimited expressive power without forcing them to give up control over their words.

Erga documents are just web pages, and any web page can be an erga document. Erga feels like a normal text editor, but it's much more powerful:

  • If it can be expressed in code, you can put it in your document
  • Use the editor to choose the words, use an agent for styling, formatting, animations, demos, etc.
  • There's no fixed document format, which means that you can use Erga for docs, slides, or anything else you can dream up
  • It's fully multi-player. Share your document URL with a friend or colleague and they can edit too.
