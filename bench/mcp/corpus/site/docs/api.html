Getting started API reference

API reference

The API is available on the Agency plan. New to Ledgerly? Start with Getting started.

Authentication

Create a key under Settings, then send it in the Authorization header of every request.

curl https://api.ledgerly.example/v1/invoices \
  -H "Authorization: Bearer lk_live_..."

Limits

Each account may make 10,000 requests a month. Requests above that cost $0.50 for each 1,000.

Endpoints

MethodPathWhat it does
GET/v1/invoicesLists invoices, newest first
POST/v1/invoicesCreates a draft invoice
POST/v1/invoices/{id}/sendSends an invoice to its client
GET/v1/clientsLists clients
GET/v1/paymentsLists payments received
