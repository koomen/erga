# Welcome to Erga

This page is a plain Markdown file, `example/index.md`, open in the editor.
Click into any text and type: your edits are written back to the file a
moment after you stop.

## Things to try

- Select a few words for the style bar, or use **⌘B**, *⌘I* and `⌘E`.
- Open this page in a second window with `?user=Ada` on the end of the
  address, and type in both.
- Change this file in another editor and watch the page follow.
- With an `ANTHROPIC_API_KEY` in `.env`, open the agent panel and ask it to
  edit the page with you.
